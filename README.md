 CampusHub, a Progressive Web Application designed to serve the campus community of university students. CampusHub addresses the fragmentation of campus life tools by providing a single unified platform that brings together study group management, carpool coordination, lost and found reporting, campus event discovery, and student chat communication into one cohesive web application.
•	Develop a Study Groups module with curated resources
•	Implement map-based Carpool Matching using Leaflet.js
•	Build a visual Lost & Found system (grid + map views)
•	Create an Events Calendar with month and list views
•	Implement a Chat & Alerts module with channels
•	Deliver a PWA installable on mobile devices
•	Implement dark/light mode and responsive design
•	Implement a guest-first authentication flow
